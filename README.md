# USA Housing Price Prediction

## Project Overview
A machine-learning web application that predicts house prices using housing-related features and trained regression models.

## Technologies Used
- Python
- Flask
- Pandas and NumPy
- Scikit-learn
- XGBoost
- HTML and CSS

## Features
- Predict housing prices from user-provided inputs
- Compare multiple regression models
- Display model evaluation results
- Access predictions through a web interface

## Evaluation Metrics
The models are evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R-squared (R²)

## How to Run
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Ensure the dataset, HTML templates, and trained model files are available in the expected locations.
4. Run `python app.py`.
5. Open `http://127.0.0.1:5000` in your browser.

## Learning Outcomes
This project demonstrates practical experience with regression models, model evaluation, and integrating machine learning into a Flask web application.
